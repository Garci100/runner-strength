# Runner Strength — app Android (PWA)

## Qué incluye
- Sesiones A y B con series, repeticiones, descansos y técnica.
- Enlaces a búsquedas de demostraciones en YouTube para cada ejercicio.
- Registro local en el dispositivo, historial y exportación CSV.
- Preferencias de recordatorios y prueba de notificación.
- Interfaz móvil instalable como PWA desde Chrome cuando se aloja en HTTPS.

## Instalar en Android
1. Aloja los archivos `index.html`, `manifest.json` y `sw.js` en un sitio HTTPS (o abre el HTML para probar en un navegador).
2. En Android, abre la URL con Chrome.
3. Menú ⋮ → **Instalar aplicación** o **Añadir a pantalla de inicio**.
4. Abre la app y configura los recordatorios.

## Limitación importante sobre alarmas
Esta entrega es una aplicación web progresiva, no un APK nativo. Los avisos web y los temporizadores de página no garantizan alarmas cuando el navegador está cerrado o el sistema suspende la app. Para alarmas persistentes, se requiere una implementación Android nativa con AlarmManager/WorkManager y permisos de notificación. Los datos de entrenamiento se guardan localmente en el navegador y no se sincronizan entre dispositivos. Borrar datos del navegador puede borrar el historial.

## Contenido de la rutina
- Sesión A: press con mancuernas en suelo, flexiones, aperturas en suelo, plancha frontal, dead bug.
- Sesión B: press con barra en suelo, flexiones con agarre cerrado, plancha lateral, crunch inverso, bird dog.
- Progresión: semanas 1–2 adaptación, 3–6 progresión, 7–8 consolidación.
